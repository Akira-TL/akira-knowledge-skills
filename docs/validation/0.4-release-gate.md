### F. Batch Review / revision-safe maintenance — PASS

maintain-batch-create 的公开 surface 只接受既有 governed proposal/candidate，不存在任意正文、任意 target 或任意 relation triple 的通用写入口。

每个 item 独立记录 governance ref、identity、revision/fingerprint basis、evidence、semantic change、approval result 与 execution result。

明确子集批准后：

- 选中 item = approved；
- 未选 item = rejected；
- approval 本身不执行 Authority mutation。

执行阶段人为制造 stale item，最终：

- fresh item → succeeded
- stale item → stale
- unapproved item → rejected
- 另一 fresh item → succeeded
- batch → partial

重复执行同一个 batch 后，已成功 item 不再次 mutation，不制造额外 revision。

failure isolation 通过：一个已批准 governance item 在 execution 前失效时，该 item failed，但独立 fresh item 仍 succeeded，batch 明确 partial。

纯 external move 场景也保持 existing governance 的 disjoint semantics；Batch 没有额外误判 stale。
